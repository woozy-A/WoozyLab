GlassLingo Support

GlassLingo는 화면 위 필요한 부분만 빠르게 이해할 수 있도록 돕는 macOS 번역 도구입니다. 문의가 있다면 이메일로 연락해 주세요.

GlassLingo is a macOS translation tool for understanding selected parts of the screen quickly. For questions, please contact us by email.

ycw012@naver.com

처음 사용할 때

GlassLingo는 화면 일부를 읽어야 하므로 macOS의 화면 기록 권한이 필요합니다.

  1. 앱을 실행하면 메뉴 막대에 GlassLingo 아이콘이 표시됩니다.
  2. macOS 시스템 설정에서 화면 기록 권한을 허용합니다.
  3. 렌즈를 열고 번역할 영역에 맞춘 뒤 크기 조절을 끝내면 번역이 시작됩니다.

문제가 있을 때

  • 권한을 허용했는데도 캡처가 안 되면 GlassLingo를 완전히 종료한 뒤 다시 열어주세요.
  • 앱을 재설치했다면 시스템 설정의 화면 기록 목록에서 GlassLingo 항목을 확인해 주세요.
  • 문의가 필요하면 위 메일로 macOS 버전, 앱 버전, 문제가 생긴 상황을 보내주세요.
