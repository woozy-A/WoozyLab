개인정보 처리방침

GlassLingo는 기본 모드에서 서버 계정이나 외부 번역 API 없이, 사용자가 렌즈로 지정한 화면 영역을 기기에서 처리하는 것을 우선합니다.

  • 기본 모드는 별도 서버, 계정, 데이터베이스 없이 동작하는 방향을 우선합니다.
  • 번역을 위해 렌즈 영역의 화면 이미지만 읽으며, 전체 화면 번역 앱이 아닙니다.
  • 무료 기본 버전은 외부 번역 API 또는 LLM API를 사용하지 않습니다.
  • 향후 고급 번역 기능이 추가될 경우, 데이터 처리 방식과 개인정보 정책을 별도로 안내합니다.

Privacy Policy

GlassLingo prioritizes on-device processing for the selected lens area and does not require an account or external translation API in the basic mode.
