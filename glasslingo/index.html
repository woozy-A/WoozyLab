GlassLingo 지원 개인정보

부분만 번역하는 맥용 렌즈

GlassLingo는 화면 위에 반투명 렌즈를 올려두고, 그 아래 영역만 OCR로 읽어 번역합니다. 복사할 수 없는 글자, 이미지 속 문장, PDF와 앱 화면까지 필요한 부분만 이해할 수 있도록 돕습니다.

지원 안내 보기 개인정보 처리 방식
화면 위 필요한 부분만 번역합니다.

GlassLingo가 필요한 순간

전체 페이지를 번역하지 않고, 지금 막힌 한 문장이나 한 영역만 확인하고 싶을 때를 위해 만들었습니다.

부분 번역 렌즈를 필요한 화면 영역에 맞추면 그 부분만 번역합니다. 전체 페이지 번역을 켰다 끄는 번거로움을 줄입니다.
복사 불가능한 영역 선택할 수 없는 앱 화면, 이미지, PDF, 영상 속 텍스트도 화면 캡처와 OCR로 읽는 흐름을 사용합니다.
온디바이스 우선 기본 번역 흐름은 Apple Vision OCR과 Apple 번역 기술을 우선하며, 별도 서버나 외부 번역 API를 사용하지 않습니다.

지원 및 사용 안내

GlassLingo는 화면 일부를 읽어야 하므로 macOS의 화면 기록 권한이 필요합니다.

처음 사용할 때

  1. 1 앱을 실행하면 메뉴 막대에 GlassLingo 아이콘이 표시됩니다.
  2. 2 macOS 시스템 설정에서 화면 기록 권한을 허용합니다.
  3. 3 렌즈를 열고 번역할 영역에 맞춘 뒤 크기 조절을 끝내면 번역이 시작됩니다.

문제가 있을 때

  1. A 권한을 허용했는데도 캡처가 안 되면 GlassLingo를 완전히 종료한 뒤 다시 열어주세요.
  2. B 앱을 재설치했다면 시스템 설정의 화면 기록 목록에서 GlassLingo 항목을 확인해 주세요.
  3. C 문의가 필요하면 아래 메일로 macOS 버전, 앱 버전, 문제가 생긴 상황을 보내주세요.

개인정보와 화면 캡처

GlassLingo는 화면을 읽는 앱이기 때문에 개인정보 보호를 제품의 기본값으로 둡니다.

  • 기본 모드는 별도 서버, 계정, 데이터베이스 없이 동작하는 방향을 우선합니다.
  • 번역을 위해 렌즈 영역의 화면 이미지만 읽으며, 전체 화면 번역 앱이 아닙니다.
  • 무료 기본 버전은 외부 번역 API 또는 LLM API를 사용하지 않습니다.
  • 향후 고급 번역 기능이 추가될 경우, 데이터 처리 방식과 개인정보 정책을 별도로 안내합니다.
