    <h1>Weatherfit 개인정보 처리방침</h1>
    <p>Weatherfit은 현재 위치의 날씨와 사용자가 정한 취향을 바탕으로 옷차림을 추천하는 iPhone 앱입니다. 이 안내는 출시용 앱에서 위치를 사용하는 방법, 기기에 저장하는 정보와 삭제 방법을 설명합니다.</p>

      <h2 id="data-heading">1. 사용하는 정보와 목적</h2>
      <dl class="facts">
        <div>
          <dt>현재 위치</dt>
          <dd>
            <p>위치 접근을 허용하면 앱에서 날씨를 불러올 때 현재 위치의 위도·경도를 확인합니다. 해당 지역의 예보와 지역 이름을 얻기 위해 Apple의 날씨 서비스인 WeatherKit과 위치 서비스에 전달합니다.</p>
            <p>앱은 사용 중 위치 접근을 요청하며, 이동 경로를 지속적으로 기록하거나 백그라운드에서 위치를 추적하는 기능은 사용하지 않습니다. 최근 추천 기록과 위젯에는 지역 이름을 저장합니다. 별도로 미리 본 코디를 같은 지역에서 유지하기 위한 코디 계획에는 위도·경도를 기기에 저장하며, 아래에 목적과 정리 기준을 설명합니다.</p>
          </dd>
        </div>
        <div>
          <dt>추천 취향과 앱 설정</dt>
          <dd>
            <p>추위·더위 성향, 외출 시간, 남성복·여성복·공용 의류 선호, 색상과 차림 취향, 덜 보고 싶은 옷, 실내 활동·냉방 관련 선택, 목선이 열린 옷에 대한 선호를 기기에 저장합니다. 앱 아이콘 선택과 계절 자동 변경 설정, 초기 설정 완료 여부도 저장합니다.</p>
            <p>다음 실행에도 설정을 유지하고 추천을 개인의 선택에 맞추기 위해 사용합니다. 설정은 변경하거나 앱을 삭제할 때까지 보관합니다.</p>
          </dd>
        </div>
        <div>
          <dt>지역 이름과 최근 추천 기록</dt>
          <dd>
            <p>추천 날짜·시각, 지역 이름, 추천 의류의 종류·색상과 식별 정보, 날씨 요약·수치, 추천 이유를 기기에 저장합니다. 같은 옷차림이 반복되는 것을 줄이기 위해 사용합니다.</p>
            <p>최근 기록은 <strong>최대 21건</strong> 보관합니다. 같은 날짜·같은 지역의 기록은 새 추천으로 갱신하며, 새 기록이 쌓여 21건을 넘으면 오래된 기록부터 삭제합니다. 21일이 지나면 삭제되는 방식은 아닙니다.</p>
          </dd>
        </div>
        <div>
          <dt>미리 본 코디와 오늘만 바꾼 옷</dt>
          <dd>
            <p>날짜, 예보를 조회한 위치의 위도·경도, 추천 설정, 날씨 판단에 사용한 수치, 의류 번호와 색상, 저장 시각을 기기에 저장합니다. 같은 날짜·가까운 지역에서 다시 열었을 때 코디를 유지하고, 날씨나 설정이 달라지면 추천을 다시 판단하기 위해 사용합니다. 사용자의 착용 사진을 저장하는 기능은 아닙니다.</p>
            <p>계획은 <strong>최대 21건</strong>을 저장합니다. 조회할 때 오늘부터 14일 뒤까지의 계획 중 마지막 저장 후 14일 미만인 계획만 사용합니다. 지난 날짜나 이 기준을 벗어난 계획은 사용 대상에서 제외하고, 다음 코디 계획을 저장할 때 저장 목록에서도 제거합니다. 앱을 사용하지 않는 동안에는 기기에 남아 있을 수 있습니다.</p>
          </dd>
        </div>
        <div>
          <dt>위젯에 표시할 최신 추천</dt>

            <p>오래된 날씨를 현재 정보처럼 보여주지 않도록 8시간이 지나거나 날짜가 바뀌면 새로 확인하라는 안내를 표시합니다. 이 표시 기준은 저장 정보의 자동 삭제 시점과는 다릅니다. 날씨 출처의 링크와 표기도 기기에 저장할 수 있습니다.</p>
          </dd>
        </div>
        <div>
          <dt>날씨 연결 진단 기록</dt>
          <dd>
            <p>날씨 연결 문제를 확인하기 위해 조회 시각, 진행 단계와 결과, 요청한 날짜의 차이와 외출 시간, 받은 예보의 개수, 오류 종류와 번호를 기기에 기록합니다. 정확한 위치 좌표, 지역 이름, 인증 값, 요청 주소와 오류 상세 본문은 이 진단 항목에 포함하지 않습니다.</p>
            <p>앱이 작성하는 진단 파일에는 최근 이벤트를 <strong>최대 32개</strong> 보관합니다. 새로운 전체 날씨 조회를 시작하면 기록 목록을 다시 시작합니다. 같은 이벤트가 기기의 시스템 로그에도 남으며, 시스템 로그의 보관 기간은 iOS가 관리합니다. 개발자 서버로 자동 전송하거나 문의 메일에 자동 첨부하지 않습니다.</p>

      <h2 id="sharing-heading">2. 외부 서비스와 정보 전달</h2>
      <p>앱에 저장한 추천 취향, 최근 추천 기록과 코디 계획을 Weatherfit 개발자 서버로 전송하지 않습니다. 회원 계정, 광고 식별자, 광고 SDK 또는 이용자 행동 분석·추적 서비스를 사용하지 않습니다.</p>
      <h3>Apple의 날씨 및 위치 서비스</h3>
      <p>출시용 앱의 날씨 제공자는 Apple입니다. Apple은 WeatherKit의 위치 정보를 날씨 제공에 사용하며 개인 식별 정보와 연결하거나 요청 사이에 위치를 추적하지 않는다고 안내합니다. 자세한 내용은 <a href="https://developer.apple.com/weatherkit/">Apple WeatherKit 안내</a>와 <a href="https://www.apple.com/legal/privacy/">Apple 개인정보 보호정책</a>을 확인해 주세요.</p>
      <h3>문의 이메일</h3>
      <p>문의 주소는 네이버 메일을 사용합니다. 메일을 보내면 선택한 메일 서비스와 네이버 메일을 통해 문의가 전달됩니다. 이메일 서비스의 정보 처리는 해당 제공자의 정책에 따릅니다. <a href="https://policy.naver.com/policy/privacy.html">네이버 개인정보 처리방침</a>을 확인할 수 있습니다.</p>
      <h3>착용 예시와 날씨 웹사이트</h3>
      <p>사용자가 아이템의 Pinterest 또는 Google 이미지 링크를 누르면 선택한 옷의 색상과 종류를 검색어로 전달합니다. 이 검색 주소에 현재 위치, 날씨 수치나 저장한 추천 기록은 넣지 않습니다. 검색 결과를 앱이 수집하거나 기기에 검색 이력으로 저장하지 않습니다.</p>
      <p>외부 페이지를 연 뒤에는 해당 서비스의 개인정보 처리방침이 적용됩니다. <a href="https://policy.pinterest.com/ko/privacy-policy">Pinterest 개인정보 처리방침</a>과 <a href="https://policies.google.com/privacy?hl=ko">Google 개인정보처리방침</a>에서 확인할 수 있습니다. 날씨 상세에서 외부 날씨 웹사이트를 여는 경우에도 해당 서비스의 정책이 적용됩니다.</p>
